# ADR-004: GitOps Controller — ArgoCD
Date: 2026-03-06 | Author: Raj | Status: Accepted

Context: Needed a GitOps controller to sync Kubernetes manifests from Git to the EKS cluster,
ensuring no manual drift and full reproducibility.

Decision: ArgoCD.

Alternatives:
- FluxCD: Less visual UI, smaller community, fewer tutorials for EKS specifically.
- Jenkins X: Too heavy for this project scope, introduces significant complexity.
- Manual kubectl apply: Defeats the reproducibility requirement entirely.

Consequences:
✅ CNCF graduated project — production proven
✅ Visual UI to demonstrate GitOps sync to recruiters
✅ Raj has prior experience
✅ Enforces the "Git is source of truth" rule automatically
⚠️ Adds initial setup complexity (CRDs, RBAC, app registration)
⚠️ ArgoCD is NOT the same as Argo Workflows — auto-remediation pipelines require Argo Workflows separately
