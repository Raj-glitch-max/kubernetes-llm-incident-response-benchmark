# ADR-001: Cloud Provider — AWS
Date: 2026-03-06 | Author: Raj | Status: Accepted

Context: Needed a cloud provider to host EKS cluster, run chaos experiments, and store benchmark data.

Decision: AWS.

Alternatives:
- GCP: Less adoption in Indian startup ecosystem, fewer relevant job descriptions.
- Azure: Higher cost for equivalent EKS-equivalent setup (AKS), less Raj familiarity.

Consequences:
✅ Industry standard in India for DevOps/Platform roles
✅ Native Cost Explorer for per-experiment cost tracking
✅ Raj has existing hands-on experience
✅ EKS integrates natively with IAM, VPC, CloudWatch
⚠️ Slightly higher baseline cost than GCP for equivalent compute
