# ADR-003: LLM Models — GPT-4 Turbo (primary) + Claude 3 Sonnet (comparison)
Date: 2026-03-06 | Author: Soham | Status: Accepted

Context: Needed LLM(s) to perform root cause analysis from Kubernetes logs, events, and Prometheus alerts.

Decision: OpenAI GPT-4 Turbo as primary model. Anthropic Claude 3 Sonnet for model comparison.
Running both on identical inputs makes the benchmark a multi-model comparison, which is stronger signal.

Alternatives:
- Local LLM via Ollama: Hardware constraints on available machines make this impractical for 50 experiments.
- Gemini: Weaker structured JSON output reliability at time of decision; less community benchmark data.
- GPT-3.5-turbo: Included as optional third model for cost comparison analysis only.

Consequences:
✅ GPT-4 Turbo produces most reliable structured JSON output
✅ Multi-model comparison = stronger, more publishable benchmark
✅ Both models have Python SDKs with simple API interfaces
✅ Both support `response_format: json_object` for enforced JSON output
⚠️ API cost per experiment — tracked via `cost_usd` field in incidents.csv
⚠️ Model versions can change — all runs must log exact model version used
