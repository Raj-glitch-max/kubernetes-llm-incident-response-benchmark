# ADR-005: Chaos Tool — Custom Bash/Python Scripts
Date: 2026-03-06 | Author: Raj + Soham | Status: Accepted

Context: Needed a way to inject controlled failures into the EKS cluster for 50 experiments
across 4 failure categories: pod, network, node, resource.

Decision: Custom Bash scripts in `k8s/chaos/`. No third-party chaos framework for core build.

Alternatives:
- LitmusChaos: CNCF project with pre-built fault library. Adds CRD overhead, cluster RBAC complexity,
  and a separate operator deployment. Overkill for a 2-week sprint with defined scenario list.
- ChaosMesh: Similar to Litmus — adds dependency, requires separate namespace and RBAC setup.
- Gremlin: Paid. Not viable.

Consequences:
✅ Full parameter control — scripts do exactly what we define
✅ No external operator dependency — simpler cluster setup
✅ Raj owns and understands every line of the chaos logic
✅ Scripts are readable and auditable by anyone cloning the repo
⚠️ Less "battle-tested" than LitmusChaos — edge cases must be handled manually
⚠️ No built-in metrics export from chaos tool (handled by Prometheus scraping instead)

Note: LitmusChaos remains a valid future upgrade path if scenario library grows beyond 20+ types.
